# 콘텐츠 변경 이력

원문: 「환경·자원순환·제로웨이스트 탄소중립 O/X 퀴즈 150문항」(PDF)

문항 문장, 정답, 해설은 원문을 그대로 데이터화하는 것이 원칙이다.
원문과 달라진 부분은 아래에 모두 남긴다.

## 2026-10-06 — 최초 데이터화

- PDF 줄바꿈 때문에 단어 중간에 생긴 공백을 원문 표기대로 붙였다 (예: "거 의" → "거의").
- 문항 끝의 `( O / X )` 표기는 화면에서 버튼으로 대신하므로 데이터에서 뺐다.
- 유사 개념 문항이 한 회차에 함께 나오지 않도록 `similarGroup`을 추가했다.

## 2026-10-06 — 133번 해설 요약

해설이 화면 한 번에 읽기에는 너무 길어(약 400자) 요약했다. 정답(X)은 그대로다.

**원문**

> 소비기한은 정해진 방법대로 보관했을 때 먹어도 안전에 이상이 없는 기한입니다. 가게에서 팔 수 있는 기한은 '유통기한'이에요. 유통기한은 팔 수 있는 기간을 기준으로 해서, 그 기한이 지나도 바로 상하는 것은 아닌데도 멀쩡한 음식이 버려지는 일이 많았습니다. 그래서 우리나라는 2023년부터 식품에 소비기한을 표시하는 제도를 시행했어요(일부 품목은 적용 시기가 뒤로 미뤄졌습니다). 소비기한은 보통 유통기한보다 더 길어서 아직 먹을 수 있는 음식을 버리는 일, 즉 음식물 쓰레기를 줄이는 데 도움이 됩니다. 단, 냉장·냉동 같은 보관 방법을 꼭 지켜야 하고, 포장을 뜯은 뒤에는 되도록 빨리 먹어야 해요.

**변경**

> 소비기한은 정해진 방법대로 보관했을 때 먹어도 안전에 이상이 없는 기한이에요. 가게에서 팔 수 있는 기한은 '유통기한'이고요. 우리나라는 2023년부터 소비기한 표시제를 시행해 아직 먹을 수 있는 음식이 버려지는 일을 줄이고 있어요. 단, 보관 방법은 꼭 지켜야 해요.

## 2026-10-13 — 고난이도 20문항 추가 (151~170)

사용자가 제공한 원고 20문항을 `level: "expert"`로 추가했다. `source.number`는 원고 번호(1~20)다.
문항·정답·해설 문장은 원고 그대로 두고 아래만 손봤다.

- 문항 끝 `(O / X)` 표기와 해설 끝의 출처 표기(「탄소중립_환경_제로웨이스트_OX퀴즈_150문항」)를 뺐다.
- 참가자에게 보여줄 내용이 아닌 출제 메모는 해설에서 `note` 필드로 옮겼다 (화면에 표시하지 않음).

| 번호 | 해설에서 `note`로 옮긴 문장 |
|---|---|
| 151 | 기존 131번을 헷갈리기 쉽게 변형한 문제입니다. |
| 152 | “온난화 효과가 크다”와 “대기 체류기간이 길다”를 혼동하도록 만든 문제입니다. |
| 154 | 소비자책임제도로 착각하기 쉬운 표현입니다. |
| 155 | 기존 116번과 148번을 합친 문제입니다. |
